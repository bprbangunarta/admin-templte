Accordion

Bagaimana cara mengubah warna tema?
Ubah variabel --accent dan --accent-soft di blok :root pada assets/css/app.css. Seluruh komponen otomatis mengikuti.
Apakah mendukung mode gelap?
Ya. Klik ikon bulan/matahari di kanan atas. Preferensi tersimpan otomatis dan mengikuti pengaturan sistem secara default.
Apakah responsif di ponsel?
Seluruh halaman dioptimalkan untuk desktop, tablet, dan ponsel — sidebar menjadi drawer, tabel bisa di-scroll, grid menyesuaikan.
Bagaimana menambah halaman baru?
Salin salah satu file di folder pages/, sertakan partial sidebar & topbar, lalu atur data-title dan data-nav pada <body>.
Apakah bisa dipakai dengan Laravel?
Bisa. Partial dipetakan ke Blade @include, folder assets/ ke public/assets/. Lihat README untuk tabel migrasi.
